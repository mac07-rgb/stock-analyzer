# Stock Analyzer

A stock analysis tool using the python programming language to get the historical data of the stock.
Uses Yahoo Finance to research data and measures price performance.

## Features

- Use the ticker symbol to search for a stock.
Automatically resolve company names to ticker symbols.
Compare the performance of stocks in the past
- Calculate total return
Using historical data, find the peak and trough prices.From historical data, determine the highest and lowest prices.
- Determine the optimal time frame for a buy/sell decision based on the historical data.
- Determine the greatest profit possible
Plot stock prices over time.Graph stock prices over time.

## Technologies

- Python
- yfinance
- Matplotlib

## How to Run

Install the libraries:

pip install -r requirements.txt

Run:

python stock_analyzer.py

When prompted, enter a stock ticker.

Example:

AAPL

## Example

The program displays:

- Starting price
- Ending price
- Total return
- Highest price
- Lowest price
- When did it hit its lowest price in the past?
- Last day to sell historically
- Maximum profit

Also produces a price chart with the significant prices.
